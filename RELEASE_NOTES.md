Free clipper plug-in for macOS (Apple Silicon), VST3 and Audio Unit. By Dani Koenig.

**Download `Knack-Installer.pkg`** and double-click it. macOS blocks it the first time: open System Settings > Privacy & Security and click "Open Anyway". Full guide: see INSTALL.txt in the ZIP or in the repository.

### New in v1.0.1
- Cleaner curve display (no GR / percent text), CLIP starts at 20 %

### Features
- One big CLIP knob: drive into the clipper, with a curve display (sine to fully squashed) and a red glow that grows with the intensity
- SOFT / HARD slider: from round soft clip to hard clip
- INPUT with level meter and CALIBRATE (auto input: loudest peak lands at -6 dBFS)
- MIX: parallel clipping, latency-compensated
- OUTPUT with limiter: 0 = 0 dBFS. Pull it down and the limiter starts, with GR meter and readout in 0.1 dB steps
- HQ: 4x oversampling (switch next to OUTPUT)
- Resizable window

Requirements: Apple Silicon Mac (M1 or newer), macOS 11 or newer.
